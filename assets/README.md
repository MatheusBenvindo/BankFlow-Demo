# 📺 Pasta de Vídeos - PainelTV

Esta pasta contém os vídeos que serão exibidos no PainelTV do Sistema de Senhas BankFlow.

## 📁 Como Usar

1. **Adicione seus vídeos** nesta pasta
2. **Formatos suportados**: MP4, WebM, OGV
3. **Resolução recomendada**: 1920x1080 ou 1280x720
4. **Duração sugerida**: 30 segundos a 2 minutos

## 🎬 Vídeos Sugeridos

Adicione arquivos com os seguintes nomes para funcionamento automático:

- `BankFlow-institucional.mp4` - Vídeo institucional principal
- `BankFlow-promocao.mp4` - Promoções e campanhas atuais  
- `BankFlow-cooperativismo.mp4` - Vídeo sobre cooperativismo
- `BankFlow-servicos.mp4` - Apresentação dos serviços

## ⚙️ Configuração

O sistema irá:
- **Reproduzir automaticamente** os vídeos em loop
- **Trocar vídeos** a cada 2 minutos (se houver múltiplos)
- **Mostrar fallback** se nenhum vídeo for encontrado
- **Controles disponíveis** para o usuário

## 📋 Exemplo de Estrutura

```
videos/
├── BankFlow-institucional.mp4
├── BankFlow-promocao.mp4
├── BankFlow-cooperativismo.mp4
└── README.md
```

## 🎯 Dicas

- **Qualidade**: Use vídeos em boa qualidade para melhor experiência
- **Tamanho**: Evite arquivos muito grandes para carregamento rápido
- **Conteúdo**: Foque em mensagens institucionais e promocionais
- **Audio**: Os vídeos começam mutados, configure audio adequado
